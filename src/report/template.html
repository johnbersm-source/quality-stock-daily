부록: PDF 원본 vs v3 방법론 요약

  • 배점 방식: PDF 원본은 10개 항목×10점(3단계 컷라인 채점, 예: ROE ≥15%→10 / ≥10%→6 / <10%→2)이고, v3는 그 10항목을 8개 블록(A22·B9·C14·D12·E7·F18·G10·H8)으로 재구성·재배점하면서 구간 안에서 연속적으로 보간해 채점한다(계단식이 아님).
  • v3만의 신설 블록(PDF엔 없음): D블록 주가방어력(12점, 과거 급락장 실측 스트레스테스트), E블록 추세·성장(7점, 매출·영업이익 3년 CAGR), H블록 거시·사이클·재료(8점, 실시간 정성평가). 세 블록 합산 27점은 v3 고유 확장분이다.
  • 게이트: 스트레스테스트·안전마진(DCF) 게이트는 v3에서 새로 추가한 필터로, PDF 원본에는 해당 개념 자체가 없다(39페이지 전체 확인).
  • 등급 기준: 두 방법론 모두 90점 이상 "최상급우량주" · 80점 이상 "우량주" · 70점 이상 "관찰대상"은 PDF 원본과 동일하다. 다만 70점 미만 등급명은 PDF 원본에 없으며, "미달"은 v3 쪽 표기를 그대로 가져온 이 파이프라인만의 확장 라벨이다.
  • 본 리포트에 실리는 기준: v3 총점이 70점(관찰대상) 미만이면 그날 해당 시장(한국/미국) 리포트 자체를 발행하지 않는다(리오님 요청 — 기준 미달 종목을 억지로 리포트에 넣지 않음).
본 리포트는 자동화된 정량·정성 스코어카드 산출 결과이며 투자 조언이 아닙니다. 데이터 결측 항목은 임의로 추정하지 않고 "N/A"로 표기했으며, 이는 저평가/고평가 판단과 무관합니다. 특히 "IFRS18 투명성" 항목의 MPM 공식화 정성평가는 IFRS18 자체가 2027년부터 의무 시행(조기적용 가능)이라 그 전까지는 대부분의 종목에서 N/A가 정상입니다(회사의 결함이 아님). 게이트(스트레스테스트, 안전마진)를 통과하지 못한 종목은 총점과 무관하게 "관찰" 등급으로, v3 총점이 70점 미만인 종목은 "미달" 등급으로 표기되며 두 경우 모두 이 리포트에는 수록되지 않습니다. "미달"은 PDF 원본에 없는 이 파이프라인의 확장 등급 표기입니다. 색상 표시(빨강=긍정/파랑=부정)는 각 항목 만점 대비 득점률 기준의 상대적 표시이며 투자 신호가 아닙니다. 투자 판단과 책임은 투자자 본인에게 있습니다.
